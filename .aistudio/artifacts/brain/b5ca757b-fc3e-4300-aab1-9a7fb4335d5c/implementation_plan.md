# AuraLyric Mini — 专为办公电脑打造的轻量级 QQ音乐歌词视觉小组件

针对 **办公电脑场景** 深度定制的袖珍型实时音频视觉小组件。摒弃占据全屏的笨重界面，采用 **紧凑型胶囊/窄条微组件（Mini Bar Widget）** 形态，尺寸仅与 QQ音乐桌面歌词条相当（默认约 `520px × 88px`，支持更袖珍的 `360px × 56px` 微缩模式），并支持通过浏览器原生 **画中画独立小窗（Document Picture-in-Picture）** 弹出为无边框置顶小挂件，低调嵌入工作屏幕角落，在不遮挡代码、文档或办公软件的前提下，提供克制而灵动的三频流体光晕、声波涟漪与节奏弹性律动。

- **确认决策 1（办公轻量级小组件形态）**：告别全屏大画布，主核心采用 **袖珍窄条小组件（Compact Lyrics Bar Widget）** 设计，提供三档办公友好尺寸：**标准伴侣条（`520×88px`）**、**迷你胶囊（`380×60px`）** 与 **极简灵动岛/微光条（`260×40px`）**，可直接拖拽定位或一键弹出为 **独立置顶画中画迷你窗（PiP Mini Window）**，贴合在 QQ音乐桌面歌词旁或屏幕边缘。
- **确认决策 2（音源与歌词模式）**：支持 **系统音频/麦克风实时监听**（捕获正在播放的 QQ音乐声音），无需接管歌词解析；组件本体既可作为 QQ音乐桌面歌词的底层流光伴侣框，也可在组件内开启单行精简节奏弹性字幕或声波指示。同时保留一键「内置轻音测试流」方便快速调校。
- **确认决策 3（办公友好的三频光晕与弹性律动）**：保留 **流体光晕粒子与声波律动波纹** 及 **低/中/高三频分段光晕 + 节奏弹性缩放**，但将所有粒子、波纹与三频光晕严格收敛在迷你小组件容器内部与微距边缘内，并提供 **「办公低调模式（Low-Profile Work Mode）」** 与 **「老板键一键静默收起（`Alt + H` / 单击折叠）」**。

## 1. 产品概览与核心理念

- **核心功能**：
  1. **三档袖珍组件尺寸与自由拖拽**：在工作区中以精致小巧的悬浮条呈现，支持鼠标自由拖拽位置、自由切换 **标准条（520×88px）**、**紧凑条（380×60px）**、**微光窄条（260×40px）**，不喧宾夺主。
  2. **原生独立置顶画中画小窗（Document PiP）**：支持一键将这个迷你视觉组件从浏览器标签页中「弹出」为独立的迷你置顶小窗口，最小可缩至几十像素高，直接停靠在桌面任务栏上方或 QQ音乐桌面歌词正下方，边写文档/写代码边享受律动。
  3. **收敛式三频乐器流体光晕（Micro 3-Band Aura）**：在小组件有限的精致空间内，左侧绽放 **低频（鼓/贝斯）** 脉冲波纹，中部随 **中频（人声/吉他/钢琴）** 与主音高平滑流动翡翠/暖青色晕，右侧随 **高频（弦乐/镲片）** 逸散细腻星尘微粒，整体边框与内嵌歌词卡槽随重拍产生柔和物理弹簧律动。
  4. **办公贴心特性（低功耗 + 老板键折叠）**：支持一键切换 30fps 办公省电帧率、调节光晕克制程度（柔和/标准/灵动），以及快捷键或单击瞬间收缩为一条仅 `6px` 高的呼吸细线，随时适应办公环境。
- **目标用户**：在工作电脑上使用 QQ音乐听歌、希望给单调的桌面歌词增添精致声学动效，但又不能干扰日常办公视线的职场人与开发者。
- **核心价值**：极小体积、极低存在感、极高精致度——像桌面上的一个微型声学呼吸灯与流体音轨伴侣。

## 2. 用户体验与视觉设计

### 关键用户流程
1. **即开即用的紧凑小组件**：打开页面后，中央直接展示实际大小的 **AuraLyric Mini 悬浮小组件（默认 520×88px）**，周围是干净克制的办公桌面模拟对位网格（可辅助观察它在屏幕角落的比例）。
2. **一键连接音频**：点击小组件悬停浮现的微型麦克风/系统音频图标（或下方折叠式微型调校抽屉），即可开启 **系统音频监听（捕获 QQ音乐）** 或播放 **内置测试轻音乐**。
3. **弹出独立小窗 / 切换袖珍尺寸**：点击小组件右上角的「弹出置顶小窗（PiP）」按钮，即可将其变成桌面独立迷你小窗口，放在 QQ音乐桌面歌词旁边；也可随时在 `标准 / 迷你 / 微光条` 三种尺寸间一键切换。
4. **参数微调与收起**：需要调整配色或灵敏度时，展开小组件下方的轻量级抽屉（宽度同样保持紧凑）；调好后一键收起抽屉，只留纯净的迷你视觉条。

### 视觉识别与主题规范
- **美学定调**：**精致桌面微件（Precision Desktop Micro-Widget）** —— 采用深邃石墨磨砂底色（`#0B0F17`）搭配细腻的 `1px` 高光微边框，确保在浅色或深色办公软件旁都干净利落：
  - **办公极光（默认）**：柔和青碧（中频）+ 暖珊瑚（低频）+ 冰晶蓝（高频），温润不刺眼。
  - **深空石墨（低调办公）**：银灰流体 + 冷白声波 + 微蓝星尘，适合严肃办公场合，视觉极为内敛。
  - **琥珀暖调（午后专注）**：暖金流光 + 琥珀波纹 + 香槟微粒。
- **字体排版（2+1 字体法则）**：
  - *组件微标题与弹性参考字幕*：`Outfit` 搭配系统无衬线体，紧凑清晰。
  - *微型控制项*：`Plus Jakarta Sans`（12px–13px），所有按钮与标签严格单行显示（`whitespace-nowrap`）。
  - *微型声学读数*：`JetBrains Mono` 等宽数字（`tabular-nums`），在小组件角落以极小字号（11px）安静显示当前主音高（如 `A4 · 440Hz`）与三频微电平。
- **紧凑布局结构**：
  - 顶栏采用轻量级单行工具条，仅包含品牌名 `AuraLyric Mini`、尺寸预设切换（`标准 520px` · `紧凑 380px` · `微光条 260px` · `办公低调模式`）以及右侧主操作 `开启音频监听`。
  - 画布主体即为 **可拖拽、可缩放、可弹出画中画的迷你小组件本体**，下方提供可一键完全隐藏的微型参数面板。

## 3. 核心产品决策与权衡

- **决策 1：主推「迷你胶囊/窄条组件 + 原生画中画独立小窗（Document PiP）」**
  - *选择方案*：将所有流体光晕、声波涟漪与三频粒子渲染封装在一个高宽比接近 QQ音乐桌面歌词栏（如 `520×88px` 或 `380×60px`）的独立微组件 Canvas 中，并集成浏览器 `documentPictureInPicture` API。
  - *原因*：在办公电脑上，全屏网页不仅占地方，切换到其他办公软件时还会被遮挡。通过迷你组件形态 + 画中画独立置顶小窗，用户可以把浏览器最小化，只留一个小小的动态光晕条吸附在屏幕边缘或 QQ音乐歌词旁。
- **决策 2：提供「办公隐身/微缩模式（Stealth Line Mode）」与低功耗控制**
  - *选择方案*：支持一键折叠为 `260×40px` 甚至 `6px` 呼吸流光细线，并支持切换“柔和办公光效（降低对比度与闪烁频率）”。
  - *原因*：工作场合需要视觉克制，避免高频闪烁分散办公注意力或引起旁人注意，同时降低工作电脑 CPU/GPU 占用。

### 核心交互与状态映射
- **尺寸与形态状态 (`widgetSize`: `'standard' | 'mini' | 'micro' | 'stealth'`)**：
  - `standard` (`520×88px`)：完整显示三频分段流光、横向声波涟漪、QQ音乐歌词伴侣对位槽及微型音高/三频指示。
  - `mini` (`380×60px`)：紧凑胶囊条，适合放在显示器角落或副屏边缘。
  - `micro` (`260×40px`)：极简流光条，仅保留核心三频流体呼吸与声波线。
  - `stealth` (`220×10px`)：办公极简隐身呼吸线，单击即可恢复。
- **画中画独立置顶模式 (`isPipActive`)**：
  - 点击小组件上的「弹出独立小窗」按钮时，调用 `window.documentPictureInPicture.requestWindow({ width, height })` 将小组件 Canvas 与微控按钮无缝移入独立置顶小窗，关闭小窗时自动归位至主页面。
